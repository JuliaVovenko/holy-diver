# Holy Diver Game

## AI Usage Statement

This project was developed with the assistance of AI tools (ChatGPT).

AI was used to:
- help understand the assignment requirements,
- suggest design improvements following object-oriented programming principles,
- assist in implementing specific features such as level abort functionality, Hall of Fame system, and input validation,
- review and refine code structure and logic.

All code was reviewed, integrated, and tested manually by the author.  
AI was used as a support tool, not as a replacement for independent work.
